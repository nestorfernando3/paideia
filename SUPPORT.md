# Soporte de Paideia

## Donde pedir ayuda

- **Bugs y errores reproducibles:** usa GitHub Issues.
- **Preguntas de uso en aula o pilotos:** abre un issue con contexto del curso, numero aproximado de participantes y modo de uso esperado.
- **Mejoras o nuevas ideas:** describe el problema pedagogico antes de proponer la solucion.

## Informacion util para soporte

- Navegador y dispositivo
- Si usas modo online o modo local
- Pasos para reproducir el problema
- Capturas de pantalla o mensajes de error
- Impacto en la experiencia docente o estudiantil

## Idioma

Se aceptan reportes en espanol o ingles.
