# Contribuir a Paideia

Gracias por tu interes en mejorar Paideia.

## Formas utiles de contribuir

- Reportar bugs con pasos de reproduccion, entorno y resultado esperado.
- Proponer mejoras de UX, accesibilidad y rendimiento.
- Mejorar documentacion para docentes y estudiantes.
- Aportar fixes pequenos y bien acotados mediante pull requests.

## Antes de abrir un PR

1. Abre un issue si el cambio es grande o modifica el flujo pedagogico.
2. Explica el problema que resuelves y por que importa.
3. Mantén los cambios enfocados y faciles de revisar.
4. Si tocas interfaz o flujo, incluye capturas o una breve descripcion visual.

## Setup local

```bash
npm install
npm run dev
```

Para pruebas en red local:

```bash
npm run start:local
```

## Criterios de aceptacion

- No romper el flujo de docente o estudiante.
- Mantener claridad de copy e interacciones.
- Documentar cambios visibles para usuarios o colaboradores.
- Priorizar accesibilidad, estabilidad y utilidad pedagogica.
