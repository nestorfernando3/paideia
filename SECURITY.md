# Politica de seguridad

Si encuentras una vulnerabilidad en Paideia, por favor no la publiques primero en un issue abierto.

## Como reportar

Envia un correo a `nestorfernando3@hotmail.com` con:

- Descripcion del problema
- Pasos para reproducirlo
- Impacto potencial
- Version o commit afectado

## Alcance

Nos interesan especialmente reportes relacionados con:

- Exposicion de datos de sesiones
- Autenticacion o acceso no autorizado
- Configuracion insegura en modo local o despliegues
- Inyeccion de contenido o escalamiento de privilegios

Hare todo lo razonable por confirmar recepcion y responder con un plan de correccion.
